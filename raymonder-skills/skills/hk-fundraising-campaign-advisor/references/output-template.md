# Output Templates（4 種 mode 的標準輸出格式）

> 根據 user 觸發的 mode，套用對應模板。中文 default 為**繁體**。

---

## Template A — 網絡籌款 plan 輸出

```
# [機構名] 網絡籌款 plan

## 1. Case summary
- 機構：...
- 受惠群體：...
- 目標金額 / 期限：...
- 第一受眾：...
- 已有 / 假設：...

## 2. 立題判斷
- 結構建議：純線上 / 線上 + 線下混合 / P2P
- Anchor 策略：拉金額（高 anchor）/ 拉人數（低 anchor）
- 建議金額 ladder：[5 檔具體數字]

## 3. 故事框架
- Headline：[一句]
- 三幕：
  - 幕一（困境）：[30-50 字 + 圖像描述]
  - 幕二（介入）：[同上]
  - 幕三（蛻變）：[同上]

## 4. 頁面結構建議
- 首屏：...
- 信任區：...
- Ask 區：...
- 成功頁：...

## 5. 種子啟動計劃
- 核心圈名單：[董事 / 員工 / 大使數量]
- 配對方：[1 個 1:1 企業 / 1 個 overhead 贊助方]
- 種子貼文 kit：[3 條 WhatsApp + 2 條 IG Story + 1 條 LinkedIn]

## 6. 裂變設計
- 成功頁分享按鈕順序：WhatsApp / FB / IG Story
- 預設分享文案：[具體文字]
- 員工 / 董事 follow-up 模板

## 7. 衝刺機制
- 中段 PK 賽分組
- 最後 72 小時動作
- 最後 24 小時動作

## 8. 致謝與升級 sequence
- D+0 / D+1 / D+3 / D+7 / D+14 / D+30 各動作

## 9. KPI 與 A/B 測試
- 主指標 / 副指標
- 建議 A/B 項目

## 10. 灵析觸點（5 個）
- [Step 3 / 4 / 5 / 6 / 7 各 1 句]

## 11. Evidence appendix
- 引用清單（5-8 條核心）
```

## Template B — 月捐 plan 輸出

```
# [機構名] 月捐計劃 plan

## 1. Case summary
- 月捐現況：人數 / 平均金額 / 留存
- 目標：1 年內新增 / 升級
- 約束：員工人手 / 系統能力 / 預算

## 2. 月捐 framing 與獨立著陸頁
- Hero headline + 1 句 impact
- 日感金額表述：[每天 HK$X]
- 1 年 impact 列舉（3 個具體成果）

## 3. 開通流程
- 金額 ladder 5 檔 + default 預選位
- 支付優先級
- PDPO PICS 雙 checkbox 草稿
- < 90 秒完成路徑

## 4. 90 天 onboarding journey
- D0 / D1 / D3 / D7 / D14 / D30 / D45 / D60 / D75 / D90 各動作 + 觸發機制 + 文案要點

## 5. Stage 4 年度續費 / 升級
- 季度 impact report 計劃
- 里程碑 / 紀念日機制
- 漸進升級 ask（+ HK$50 / 月模板）

## 6. Churn 防禦
- Involuntary：Account Updater + retry + dunning sequence
- Voluntary：取消 flow + 流失原因問卷

## 7. KPI dashboard
- 月捐 13 個月留存（目標 70%+）
- D+90 升級率
- Involuntary churn / year
- Voluntary churn / year

## 8. 灵析觸點

## 9. Evidence appendix
```
