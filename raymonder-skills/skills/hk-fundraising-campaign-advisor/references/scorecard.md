# Review Checklist + 100 分 Scorecard（mode 4）

> 當機構帶著現有的捐款頁、月捐 onboarding、或 e-Flag 內容回來 review 時，用這份對照表做診斷 + 評分 + 改寫建議。
> 三個 pillar 各有獨立 scorecard，總分均為 100 分。

---

## 通用「即興 review」清單（5 分鐘版，NGO 自檢用）

對任何 HK NGO 在線募款頁，5 分鐘內掃過這 12 條：

| # | 檢查項 | 過 / 不過 |
|---|---|---|
| 1 | 首屏有機構 logo + section 88 認證 + 1 句使命 |  |
| 2 | 首屏有具名受惠者圖 + headline（非統計開頭） |  |
| 3 | 5 檔金額按鈕 + default 預選非第 1 檔 |  |
| 4 | 支付方式有 FPS + 信用卡 + Apple Pay（≥3 種） |  |
| 5 | 必填欄位 ≤ 5 |  |
| 6 | 三幕故事結構（困境 → 介入 → 蛻變）每幕 1 圖 |  |
| 7 | 信任區（過往 impact + 審計 + Privacy）並列 |  |
| 8 | 成功頁有一鍵分享按鈕（WhatsApp 第一順位） |  |
| 9 | 自動電子收據（IRD 編號）已配置 |  |
| 10 | PDPO 直銷 PICS 拆兩個 checkbox（收據 / 推廣） |  |
| 11 | 一次性轉月捐 lightbox 在 checkout 或 thank-you |  |
| 12 | 真人姓名作為 thank-you email sender |  |

每過 1 條 = 8 分，最高 96 分 + 4 分加分項（手機完成率測過 / 校網或企業合作伙伴在線 / 配對方已上線 / 真人 thank-you 電話流程）= 100 分。

## 網絡籌款 Scorecard（100 分）

| 維度 | 分值 | 評分依據 | 證據參考 |
|---|---|---|---|
| **1. 首屏與信任** | 15 | Logo、認證、單句使命、CTA 在折線以上；圖像為具名受惠者 | HKCSS 2009 (91% 重視聲譽 / 86% 透明) |
| **2. 故事與圖像** | 15 | 三幕結構；受惠者自助 framing；非 stock photo | Small 2007 / Lee & Feeley 2023 / Wang 2024 |
| **3. Ask string 設計** | 15 | 5 檔金額；default 預選非第 1；anchor 對齊目標（拉額 / 拉人）| Athey 2024 |
| **4. 支付與表單摩擦** | 15 | ≥3 種支付（含 FPS）；必填 ≤ 5；mobile 完成率 ≥ 15% | M+R 2025 / HKMA FPS |
| **5. 行政費透明 / 配對** | 10 | 若 cover overhead 已標；1:1 配對訊息在 ask 前 | Gneezy 2014 / Karlan-List 2007 |
| **6. 種子啟動** | 5 | 公開上線時 ≥15% 目標；核心圈 token-link 模式 | Seed strategy |
| **7. 裂變與成功頁** | 10 | 一鍵分享按鈕；預設文案；不付 incentive；WhatsApp 第一 | Castillo 2014 / Digital 2025 HK |
| **8. 衝刺機制** | 5 | 中段排行榜 + 最後 72 小時配對倍增 | 99 公益日 / 聯勸 |
| **9. 致謝與升級** | 10 | 真人姓名 sender；D+7 真人接觸；D+30 月捐升級 ask | Burk / NextAfter / Classy 2023 |

**評分等級**：
- 90-100：行業領先；可作 case study。
- 75-89：堅實基底，1-2 個 P0 改善即可進階。
- 60-74：3-5 個 P0 改善必須做。
- < 60：建議從架構重做，不要修補。

## 評分後該怎麼做（P0/P1/P2）

| 等級 | 定義 | 修復時間 |
|---|---|---|
| **P0** | 阻塞信任、合規、付款、理解（如：無 section 88 認證、PDPO 違規、付款方式只有 1 種、首屏無使命） | 立即修；< 2 週 |
| **P1** | 可顯著提升轉化 / 留存 / 分享（如：金額 ladder 重設、加 Apple Pay、改 ask string、加真人 sender） | 計劃內；< 6 週 |
| **P2** | 優化 / 測試 / 後期（如：A/B 不同首屏圖、加 lightbox 升級、季度 impact report 格式優化） | Roadmap；可排到下季 |
