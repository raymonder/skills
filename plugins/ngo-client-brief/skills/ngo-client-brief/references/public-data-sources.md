# 公开数据源清单

生成 HK NGO 会前简报时，按以下优先级逐条查询。每家机构不一定每条都有结果，但按这个顺序查不容易漏。

## 机构本身

| 源 | 能查到什么 | 备注 |
|---|---|---|
| 机构官网 | 组织架构、服务单位、支付方式、招聘岗位、最近活动、年度财报 PDF 下载链接 | **最重要的单一信源** |
| 机构 Facebook 专页 | 活跃度、发帖类型（活动/法会/公告/筹款）、近期事件 | 搜 `facebook.com/<英文简称或中文名>` |
| 机构 YouTube / Instagram | 受众、内容调性 | 通常活跃度不如 FB |
| 机构年报 / Annual Report | 理事会名单、全年活动、财务摘要 | 部分机构只提供纸质版 |

## 机构注册/合规信息

| 源 | URL | 能查到什么 |
|---|---|---|
| 维基百科 | `zh.wikipedia.org` | 成立年、前任负责人、重要历史事件 |
| HKCSS NGO 数据库 | `ngo.hkcss.org.hk/ngo/<id>?lang=tc` | 机构简介、服务范围、联络资料 |
| HKNGO 目录 | `hkngo.hk/hk/org/<slug>` | 成员等级、对应 HKCSS 关系 |
| 公司注册处（搜册网）| `www.icris.cr.gov.hk` | 如果是有限公司，董事变更记录 |
| 税务局慈善团体名册 | `www.ird.gov.hk/chi/tax/ach_index.htm` | 是否 Section 88 豁免 |

## 政府资助与监管

| 源 | URL | 能查到什么 |
|---|---|---|
| 社福署 iConnect | `www.swd.gov.hk/iconnect` | 受助机构名单、服务单位列表 |
| 社福署 elderlyinfo | `elderlyinfo.swd.gov.hk` | 安老院宿位数、评级、主管 |
| 社福署 151 | 综合 NGO 资讯 | |
| 社署 LSG 整笔拨款名单 | 每年公布 | 确认机构拿多少 LSG |
| 劳工及福利局 | `www.lwb.gov.hk` | 政策动态、改革方向 |
| 卖旗日批准名单 | 搜 `"<机构名>" 卖旗` 或查 `hkngolist.com` | 近 3 年卖旗日期 + 分区 |

## 见面对象本人

按优先级逐一查：

1. LinkedIn（英文名 + 机构名）
2. Google News 新闻（中文名 + 机构名）
3. 机构官网的高层介绍页
4. 机构 Facebook 上的活动照片（往往能看到中层管理者被 tag）
5. 论文数据库（CUHK、HKU 的 thesis 存档——NGO 管理层不少是社工硕士）

**查不到是常态**。HK NGO 中层经理通常没有公开足迹——这不是失败，只是一个数据点。查不到就在简报里注明「会议必问」。

## 怎么用搜索引擎

搜香港 NGO 资料，Google 搜索技巧：

- `"<机构中文名>" filetype:pdf` — 找年报、财报、章程
- `site:<官网域名> <关键词>` — 在官网内搜索
- `"<机构名>" 招標 OR 採購 OR 資訊科技` — 找 IT 招标
- `"<机构名>" 月捐 OR 定期捐款 OR 每月支持` — 找月捐痕迹
- `"<机构名>" 賣旗 OR "flag day"` — 找卖旗日历史
- `"<机构名>" 招聘 OR 職位 OR Careers IT OR 資訊` — 找 IT 岗位招聘

## 什么时候该停止查

简报不是百科全书。停查的信号：

- **5 阶段工作流每个 phase 都有产出**——即使某阶段结论是「没有公开数据，推估为 X」，也算有产出
- **最硬的那组数字（年度财报）已经拿到**——拿到财报后继续查的边际效用很低
- **查超过 1.5 小时还在加新信源**——八成是在重复验证而不是挖新信息，应当收手写简报
