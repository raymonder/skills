# 可套用模板

开新项目时复制这一篇里的骨架直接填。这些模板把主纲第一节「事实底座」和几张关键表落成现成格式。占位符用 `<…>` 标注，方括号 `[★]` 表示「假设值 / 待用户校正」。

---

## 模板 A：交接简报 / 项目上下文（自带上下文，可当首条 prompt）

> 这是本方法论最有价值的产出之一。整篇喂给新 session / 新接手人，无需重读原始材料即可接手。决策有更新就升版本，以最新版为准。

```markdown
# 项目上下文交接（v<N>）｜<项目名> 投标

> 用途：自带上下文的交接文档，整篇喂给另一个 AI / 新 session 即可接手。
> 相对上一版的变化：<本版新增 / 修改了什么>。以本版为准。

## 〇、给接续者的总指令（可当首条 prompt）
你在协助为 <我方公司> 撰写 <客户 / 项目> 的 <RFP/RFQ> 投标方案。续写 / 修改时遵守：
1. 逐条对齐招标要求：每条承诺能回标某条款 / 需求编号。
2. 数字三处一致：报价人日 ↔ 工期 ↔ 团队人力，对齐第五节数字底座。
3. 竞品红线：正文不点名对比友商、不暴露未授权的内部项目 / 客户名。
4. 口径固定：<架构 / 技术 / 可选边界等锁定项>，禁止出现 <冲突说法>。
5. 语言规范：<正文语言 / 界面示例语言 / 配图文字语言>。
一次只改一块，改完即可。
```
