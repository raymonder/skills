# Intake（所有 mode 共用）

> 這份 intake 是 4 個 mode 的共同入口。任何一個 pillar 都先跑這份。
> **重要**：實際 skill workflow 已升級為「Step 0a 基礎研究 + Step 0b 必要輸入 gate + Step 0c 缺 HARD 就 STOP」三段式（見 SKILL.md）。下面的 A-G 是完整的問題清單；實際使用時，Claude 應先用 web 工具自動填可查到的部分，把剩下的劃分為 HARD（不齊全就停）/ SOFT（可假設但標註）兩類。

## HARD 必要輸入（缺一不可，否則 STOP）

| # | 項目 | 缺了會怎樣 |
|---|---|---|
| H1 | Pillar 選擇（網絡籌款 / 月捐 / 卖旗 e-Flag / Review） | 4 套 play 完全不同 |
| H2 | 目標：金額 OR 人數（二選一） | anchor 設計反向 |
| H3 | 期限 / 場景（briefing / plan / review report；多久內） | 決定深度 |
| H4 | Review mode 限定：現有資產 URL 或截圖 | 沒東西可 review |

## SOFT 可假設輸入（標明「以下為假設」）

| # | 項目 |
|---|---|
| S1 | 過去 12 個月籌款活動數量 / 結果 |
| S2 | 員工可投入工時 / 籌款部規模 |
| S3 | 校網 / 企業 CSR / HKJC 馬會基金 / 教會關係 |
| S4 | 既有 CRM / 支付方式現況 |
| S5 | 跟對方關係狀態（首次拜訪 / 已合作 / 客戶服務中） |

## Step 0a 基礎研究 checklist（Claude 自動填）

從 WebSearch + 官網 + 年報 + data.gov.hk 應該能查到的：
- [ ] 機構類型 + 受惠群體
- [ ] 成立年份 + 規模指標
- [ ] IRD section 88 狀態
- [ ] HKCSS 會員狀態
- [ ] 過往賣旗日紀錄（data.gov.hk 公開）
- [ ] 現有在線捐款 / 月捐產品（含 URL）
- [ ] 品牌調性 / 最近 campaign / 最近新聞
- [ ] 審計事務所（信任 posture 線索）

完成後輸出一頁「我已知的事實」給用戶 confirm。

## 完整 A-G 詳細問題清單（用戶有空可全填）

## A. 機構基本面

1. **機構類型**：學校 / 註冊 NGO / 慈善信託 / 醫療機構 / 教會 / 校友會 / 基金會 / 社會企業？
2. **稅務地位**：是否已獲 **IRD section 88** 慈善豁免？年份？
3. **服務對象**：受惠群體（兒童 / 青少年 / 長者 / 殘疾 / 醫療 / 動物 / 環境 / 文化 / 倡導等）。
4. **規模指標**：年度總收入、員工數、董事會構成、過去 12 個月籌款活動數量。
5. **品牌資產**：機構成立年份、known-for 故事 1 句、近 3 年最有代表性的服務成果。

## B. 現有資產（決定哪個 pillar 可即時切入）

### 網絡籌款
- 是否已有獨立的線上捐款頁？（URL）
- 主流支付方式（FPS / Visa / Master / AlipayHK / WeChat Pay HK / Apple Pay / PayMe / 八達通）？
- 過去 12 個月的線上籌款活動、目標、達成？
- 是否有過社交媒體分享裂變實驗？結果？

### 月捐
- 是否已有月捐計劃？產品名？
- 月捐人數量、平均月捐金額、年留存率？
- 是否有 onboarding sequence（welcome email、致謝電話、第一份 impact report）？
- 月捐失敗付款（信用卡到期 / 餘額不足）的處理流程？

### 卖旗 / e-Flag
- 是否有 PSP（公開籌款許可證）？哪一年的賣旗日？全港還是分區？
- 過去賣旗日的籌款金額、義工團隊數、線上線下比例？
- e-Flag 平台用哪個（SparkRaise / Flag-Bag Easy / 自建 / 灵析 / 其他）？

## C. 捐方基礎（決定 propagation loop 規模）

1. 現有捐贈者數量（一次性 + 月捐 + 大額）。
2. 主要 donor 類別：個人 / 校友 / 家長 / 企業 / 基金會。
3. 過去 12 個月新獲取 vs 流失？
4. 是否有 lapsed donor 名單？最近一次 reactivation 的時間？

## D. 動員網絡

1. 義工數量、團隊構成（董事 / 員工 / 義工 / 校友）。
2. 是否有校網 / 企業 CSR / 賽馬會基金 / 教會等網絡？
3. 是否有 KOL / 大使 / 明星義工合作？

## E. 渠道與工具

- 現用 CRM / fundraising tool？
- 主要對外渠道：機構網站、IG、FB、WhatsApp broadcast、Email、LinkedIn、TikTok、小紅書、YouTube？
- 每個渠道的 follower / list size？

## F. 約束

- 私隱（PDPO 直銷同意管理現況）。
- 兒童 / 醫療 / 受助人形象使用政策。
- 法律審批（董事會、社署、IRD）。
- 品牌調性（嚴肅 / 溫情 / 倡導 / 行動派）。
- 語言（繁體中文為主 / 雙語 / 英文）。
- 員工人手能 commit 的 campaign 工時 / 月。

## G. 目標與期限

1. 本次計劃的目標金額？deadline？
2. 是否硬目標還是 stretch goal？
3. 失敗會發生什麼（董事壓力、項目停擺、機構聲譽）？

## 預設可繼續執行的最少資訊

如果以下 7 條齊全，可直接跑 plan，不必再追問：
1. 機構類型 + 受惠群體
2. 是否有 section 88
3. 當下要做的 pillar（網絡籌款 / 月捐 / 卖旗）
4. 目標金額 + deadline
5. 現有捐方 / 義工 / 校網規模
6. 主要支付方式現況
7. 員工人手能投入的工時

不足時：列出缺什麼 + 寫明「以下用合理假設展開，請日後校正」。
