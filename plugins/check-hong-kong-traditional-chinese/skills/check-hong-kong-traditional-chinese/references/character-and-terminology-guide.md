## 判斷級別

| 級別 | 定義 | 處理 |
| --- | --- | --- |
| A：必須修正 | 簡體殘留、明顯錯別字、缺字／重字、錯誤專名 | 在授權範圍內修正，避開引文及識別字 |
| B：香港慣用 | 香港正式文件及本地機構通常採用的字形或詞語 | 面向香港讀者時優先採用 |
| C：項目統一 | 多種寫法均成立，項目選定其中一種 | 依項目字彙表統一，不宣稱其他寫法錯誤 |
| D：按語境判斷 | 同一詞在不同語境有不同譯法 | 人工閱讀，不可機械替換 |

## 常見字形及明顯錯誤

| 候選問題 | 建議 | 級別／說明 |
| --- | --- | --- |
| 羣 | 群 | B；例如「義工群組」 |
| 户 | 戶 | A；簡體殘留 |
| 説 | 說 | B；香港慣用字形 |
| 閲 | 閱 | B；例如「查閱」 |
| 衞 | 衛 | B；香港慣用字形 |
| 爲 | 為 | B；香港慣用字形 |
| 啓 | 啟 | B；例如「啟用」 |
| 覈 | 核 | C；一般項目可統一為「批核／審核」 |
| 臺 | 台 | C；一般產品介面可用「平台／後台」，專名除外 |
| 裡／裏 | 依項目選定 | C；兩者不可只憑字形判錯 |
| 乎合 | 符合 | A；OCR 或輸入錯誤 |

常見簡體殘留包括「用户、账户、说明、查阅、卫星、群组、设置、默认、导出、导入、审批、自定义、界面、模块、志愿者」。這一類通常是 A 級，但引用原文、程式鍵名及第三方專名仍須保留。

## 語境依賴詞

- 「數據」可指統計數字；泛指 data 時常用「資料」。
- 「文件」可指正式文書；computer file 常用「檔案」。
- 「下載」是取得既有檔案；「匯出」是把資料轉成輸出檔案。
- 「審核」適合內容或資格檢查；「批核」適合行政批准；「評核」適合表現評估。
- 「群組」適合通訊、權限或收件人集合；「組別」適合業務分類。
- 「訊息」可指系統訊息；「資訊」指一般 information；「消息」可指即時通訊內容。
- 公文可用「遞交申請」，介面按鈕可用「提交」。
- 「志願者」在香港社福語境通常用「義工」；排班相關用詞可按機構採用「編更、當值、更表、調更」，但不得脫離客戶業務字彙表批量替換。
- 「職員、員工、同工」取決於機構文化；不是單純繁簡問題。

## 人工覆檢

- 缺字、重字、斷句錯誤、OCR 形近字及標題與正文不一致。
- 同一概念混用多個譯名，例如「範本／模板」「群組／組別」。
- 內地式標題或宣傳語，例如「賦能、抓手、閉環、落地」；改寫前先確認原意。
- 中文正文的全形標點，以及日期、時間、金額格式是否全篇一致。
- 英文專名、法例、機構名稱、商標、引文、程式碼及資料鍵有否被誤轉。
- 圖片、圖表、白板、試算表、頁首頁尾、註解及 metadata 中的殘留文字。
