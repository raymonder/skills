# 香港繁體用字檢查

## 核心原則

把目標定為「香港讀者自然、準確地理解」，不要把簡體字機械轉碼成繁體字。先閱讀 `references/character-and-terminology-guide.md`，按 A 至 D 四級判斷；需要查證字形、資訊科技用語、法律或機構專名時，再閱讀 `references/sources.md`。

- A「必須修正」：簡體殘留、OCR 錯字、缺字、重字及錯誤專名。
- B「香港慣用」：香港正式文件通常採用的字形或詞語。
- C「項目統一」：多種寫法均成立，由項目字彙表選定一種。
- D「按語境判斷」：不同意思需要不同譯法，不可批量替換。

不要把 B、C、D 級項目宣稱為普遍錯字。客戶既有術語、法定名稱、品牌名稱、原文引述及程式識別字優先於一般對照表。

## 工作流程

1. 確認本次範圍及權限：哪些是本次交付、哪些只是參考材料、是否允許直接修改。沒有明確授權時先報告，不要寫回。
2. 尋找項目字彙表、風格指南及客戶既有文件，記錄已選定的 C 級寫法。
3. 盤點所有文字載體，不只掃正文：
   - 原始碼、Markdown、純文字、HTML、JSON、YAML、XML、CSV、字幕及在地化檔案；
   - 文件標題、表格、圖說、連結顯示文字、metadata、頁首頁尾及註解；
   - 可編輯圖表、白板、電子表格、附件及其他內嵌資源；
   - 圖片內文字。圖片預設只預覽、OCR 或列出待檢查項，不得修改或重新生成。
4. 使用 `scripts/scan_hk_traditional.py` 做第一輪確定性掃描，再人工逐句覆檢上下文、缺字、重字、斷句及同義詞混用。
5. 先列出發現，標明檔案／頁面／區塊、原文、建議、級別及理由。圖片問題另列來源位置和圖片檔名或資源識別碼。
6. 只修正獲授權的內容。A 級可直接修正，但仍要避開原文引述、不可改資源及識別字；B 至 D 級要依客戶用法及上下文決定。
7. 寫回後重新讀取並掃描，確認問題已消失，且段落、表格、連結、圖片、圖表節點及內嵌資源的數量和順序未被破壞。

## 掃描器

從 Skill 目錄執行：

```bash
python3 scripts/scan_hk_traditional.py /path/to/project
python3 scripts/scan_hk_traditional.py /path/to/project --format json
python3 scripts/scan_hk_traditional.py /path/to/project --ignore 'vendor/**' --ignore 'quoted-sources/**'
python3 scripts/scan_hk_traditional.py /path/to/project --allow '模板' --allow '回滾'
```

掃描器會遞迴讀取常見文字檔，略過依賴、版本控制、建置產物及二進制檔，並列出圖片供人工檢查。它不會修改任何檔案。退出碼為：找到 A 級問題時 `1`，只找到 B 至 D 級或沒有問題時 `0`，執行錯誤時 `2`。

把詞典、測試樣本、翻譯對照表、引用原稿及刻意展示錯誤寫法的文件加入 `--ignore`；把客戶或項目明確保留的詞逐一加入 `--allow`。否則掃描器會如實命中其中的反例。保留清楚的排除及允許清單，並在結果中說明未檢查範圍。

掃描結果只是候選清單：不要僅憑命中詞直接替換。PDF、DOCX、飛書文件、試算表、投影片或設計檔要使用相應工具讀取完整結構；掃描器不能取代格式與視覺覆檢。

## 輸出格式

按以下順序交付：

1. 已修正：列出位置、原文與改後文字。
2. 待確認：列出 B 至 D 級或專名／引文問題及判斷依據。
3. 圖片殘留：逐項列出圖片所在文件或連結、圖片檔名／識別碼、可見原文與建議；明確註明未修改。
4. 範圍與驗證：說明已檢查及未能檢查的載體、使用的項目字彙表、重掃結果及結構驗證。

若沒有某一類發現，明確寫「未發現」，不要省略範圍說明。
